## 🌌 About SOLARIS

**SOLARIS** is an interactive space exploration and educational gaming experience developed by Team Hyperion for the NASA Space Apps Challenge 2026.

Our project aims to introduce young learners to astronomy, space exploration, and the challenges of operating in space through an engaging and interactive experience.

By combining educational content with browser-based gameplay, SOLARIS encourages players to explore astronomical concepts while experiencing mission-related challenges.

## 🌐 Live Experience

🚀 **Play SOLARIS:** [Launch Website](https://solarisbyhyperion.netlify.app/landing.html)

> 💻 **Recommended Experience:** We strongly recommend using a laptop or desktop computer for the best experience. Some gameplay elements and visual features are better experienced on a larger screen.

## 🎮 Project Features

- **Interactive Landing Page** – Explore the SOLARIS project and its educational content.
- **Space-Themed Gameplay** – Experience an interactive space exploration environment.
- **Mini-Games** – Complete different mission-related challenges.
- **Astronomy Showcase** – Explore educational content related to astronomy and space.
- **Multimedia Experience** – Includes visual and audio elements to enhance the experience.

## 🚀 Getting Started

You can experience SOLARIS directly through the live website or run the project locally.

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/hsulinaung/solaris.git
   ```

2. Open the downloaded project folder.

3. Open `landing.html` in your web browser.

4. Click the game launch button to start exploring SOLARIS.

**Note:** For the best local development experience, use a local development server such as VS Code Live Server, especially if the project loads external JSON files using JavaScript `fetch()`.
